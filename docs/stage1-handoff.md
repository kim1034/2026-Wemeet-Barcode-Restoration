# 1단계(검출) → 2단계(기하 추정) 인계 규격

**누가 읽나**: 1단계 팀 (김시선 · 조아라 · 이다현)
**한 줄로**: **자른 그림 + 몇 도 돌렸는지 + 얼마나 확실한지**, 이 셋만 주시면 됩니다.

---

## 넘길 것 — 셋

```python
DetectedBarcode(
    crop_bgr_uint8 = ...,   # 잘라낸 그림. BGR 3채널, 0~255
    angle_deg_ccw  = ...,   # 기울기를 몇 도 돌려 바로 세웠는지 (반시계, 도)
    confidence     = ...,   # 0.0 ~ 1.0
)
```

계약은 `wemeet/schemas.py` 에 이미 있고 **바뀌지 않습니다.**

---

## 제어점은 안 찍어 주셔도 됩니다

헷갈리기 쉬운데, "점"이 두 종류이고 역할이 다릅니다.

| | 누가 만드나 | 무엇을 말하나 |
|---|---|---|
| **네모 네 점** (OBB) | **1단계** | 바코드가 **사진 어디에** 있나 |
| 격자점 18개 | 2단계 | 그 안이 **얼마나 휘었나** |

1단계는 **"여기 있다"까지**입니다. 격자점은 2단계 모델이 예측하는 것이라
넘겨주실 필요가 없습니다.

---

## 지켜주셔야 할 것 — 셋

### ① 바코드를 잘라먹지 마세요 ← 가장 중요

바코드 양 끝에 **"여기서 시작 · 여기서 끝"** 표시가 있습니다.
그게 잘리면 **어떤 방법으로도 못 읽습니다.** 실험으로 확인했습니다.

| 자른 정도 | 되펴서 읽기 |
|---|---|
| 여유 있게 크게 (+8~15%) | **성공** |
| 딱 맞게 (−2%) | 성공 (아슬아슬) |
| 조금 잘라먹음 (−6%) | **실패** |

**여유를 두고 크게 자르는 쪽이 안전합니다.** 주변 글자나 테두리가 들어와도 괜찮습니다 —
2단계 학습 데이터에 그런 경우를 섞어 넣을 수 있습니다.

### ② 크롭 크기를 통일하지 마세요

**자른 그대로, 원본 해상도로** 주세요. 256×256 같은 고정 크기로 맞추지 마세요.

이유가 셋입니다.

- 2단계와 3단계가 **"크롭 폭의 몇 %"** 로 좌표를 주고받습니다. 크기를 미리 바꾸면
  원래 크기를 잃어버려서 3단계가 이미지를 되펼 때 배율을 모릅니다
- **가장 얇은 막대가 몇 픽셀인지**가 이 프로젝트에서 가장 중요한 숫자입니다.
  작은 크롭을 늘려도 막대가 굵어지는 게 아니라 뭉개진 채 커집니다
- 모델에 넣을 고정 크기 변환은 **2단계 안에서** 합니다

### ③ 기울기 보정은 완벽하지 않아도 됩니다

**±5° 남아도 괜찮습니다.** 2단계가 같이 폅니다. 실험에서 12°까지도 잘 됐습니다.

`angle_deg_ccw` 에 **실제로 돌린 각도를 적어주시면** 됩니다. 나중에 원본 좌표로
되돌릴 때 쓰입니다.

---

## 요청 — 크롭 폭을 로그에 남겨주세요

실촬영을 시작하면 **크롭이 가로 몇 px 인지 분포**를 알려주세요.

이 숫자가 2단계 설계의 핵심 변수입니다. 바코드는 **막대 굵기의 비율**로 읽는데,
가장 얇은 막대가 5px 이면 꽤 휘어도 그냥 읽히고 2px 이면 같은 정도로 휘어도 깨집니다.

| 가장 얇은 막대 | 2단계가 값을 하는 비율 |
|---|---|
| 약 2 px | **12~18%** |
| 약 3~4 px | 7% |

**현장 카메라가 5px 을 준다면 2단계가 할 일이 거의 없습니다.**
그 판단을 하려면 이 분포가 필요합니다.

크롭 폭을 165 로 나누면 가장 얇은 막대 굵기가 나옵니다
(Code128 10자리, 여백 포함 기준).

## 아직 안 정해진 것 — 같이 정해야 합니다

**송장 한 장에 바코드가 여러 개면 어느 것을 처리하나요?**

계약이 앞뒤가 안 맞습니다.

```python
PipelineResult.detected      # 하나만 담는다
DecodeResult.candidate_count # "탐지된 바코드 총 개수" — 여러 개를 전제
```

지금은 "confidence 1등만 처리한다"고 되어 있는데(설계 §5),
그 근거가 "물류 현장에서 흔하다"는 추측입니다.
`0001` 에 "송장 한 장에 바코드가 몇 개인가"가 확인 항목으로 있으니,
답이 오면 정해야 합니다.
