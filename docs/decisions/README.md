# 결정 기록

무엇을 왜 그렇게 정했는지 남기는 곳이다.

## 왜 이걸 쓰나

이 프로젝트는 **모델을 정해놓고 시작하는 게 아니라 후보를 비교해서 고른다.** 그러면 나중에 반드시 이런 질문을 받는다.

> "왜 이 모델을 골랐나요?"
> "왜 목표를 90%로 잡았나요?"

11월에 기억을 짜내서 답하려면 늦다. 결정할 때마다 그 자리에서 적어두면, **11월 보고서는 새로 쓰는 게 아니라 여기 쌓인 것을 엮는 작업**이 된다. 기획서 2.2의 산출물 "기술 문서 및 성능 평가 결과 보고서"가 여기서 나온다.

## 쓰는 방법

1. 실험이나 조사를 하기 **전에** "무엇을 정하나"와 "비교 기준"을 채운다
2. 실험 결과를 표에 넣는다. W&B 실행 이름을 같이 적는다
3. 정하고 나면 "결정과 이유"를 채우고 맨 위 상태를 `결정`으로 바꾼다
4. 나중에 뒤집히면 지우지 말고 아래에 추가한다 — **왜 바뀌었는지가 정보다**
