## 후보

| 후보 | 장점 | 단점 |
|---|---|---|
| **U-Net** | 단순. 학습 빠름. 스킵 커넥션이 바 경계를 잘 보존 | 아주 심한 훼손에 한계 |
| **Pix2Pix** (조건부 GAN) | 결과가 선명함 | 학습 불안정. 시간 오래 걸림 |

**베이스라인**: CLAHE만 적용한 결과. AI 모델이 이보다 못하면 의미가 없다.

## 손실 함수 설계

이 파트의 핵심이다. 픽셀 오차만 줄이면 흐릿한 결과가 나오고, **흐리면 디코더가 못 읽는다.**

| 항목 | 역할 | 초기 가중치 |
|---|---|---|
| L1 | 기본 픽셀 오차 | 1.0 |
| **Edge / Gradient** | 바 경계 선명도 보존 | 0.5 |
| SSIM | 구조적 일치도 | 0.3 |

가중치는 실험으로 정한다. **이 프로젝트의 학술적 차별점이 여기 있다** — 기존 복원 연구는 사람 눈에 자연스러운 화질(PSNR 중심)을 추구했고, 우리는 기계 판독을 직접 최적화한다.

## 비교 기준

| 기준 | 목표 | 측정 대상 |
|---|---|---|
| **SSIM** (주지표) | 0.85 | **합성 검증셋 전용** |
| PSNR (보조) | — | 합성 검증셋 전용 |
| 복원 후 디코딩 성공률 | `0005`에서 확정 | 실촬영 `dev` |
| **추론 시간 (ms)** | **250ms 이하** | 전체 500ms 중 배정분 |

**SSIM은 실촬영 데이터에서 측정할 수 없다.** 구겨진 비닐 사진에 픽셀 정렬된 평탄한 정답 이미지가 물리적으로 존재하지 않기 때문이다. 같은 송장을 펴서 다시 찍어도 픽셀이 정렬되지 않는다. 상세는 `0005`.

### 주의: SSIM이 높은데 못 읽히는 경우

실제로 발생한다. 그래서 **디코딩 성공률을 같이 봐야 한다.** SSIM은 복원 품질의 대리 지표일 뿐이고, 최종 목표는 기계가 읽는 것이다.

W&B에 원본·복원·정답 이미지를 나란히 올려서 눈으로도 확인한다.
